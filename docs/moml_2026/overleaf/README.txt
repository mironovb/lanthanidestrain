MoML 2026 submission -- Overleaf package
=======================================
1. Create a new Overleaf project and upload the contents of this folder
   (main.tex and the figures/ directory).
2. Add the MoML style file log_2022.sty from the MoML example template
   (Overleaf: "MoML example style files") next to main.tex.
3. Set the compiler to pdfLaTeX and compile. The bibliography is embedded
   in main.tex (filecontents writes refs.bib on the first compile; run the
   full pdflatex -> bibtex -> pdflatex -> pdflatex cycle, which Overleaf does
   automatically).
Rules: 2-4 pages of main text; references and appendices do not count.
Under a plain-article stand-in for the style the main text ends on page 4;
check the page break again under the real style.
Open items: author e-mails (three TODOs), acknowledgements, co-author consent.
